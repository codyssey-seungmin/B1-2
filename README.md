# 브랜드 아이덴티티

## 브랜드명

**Samsung Galaxy Glass**

## 브랜드 소개

Galaxy Glass는 사용자가 바라보는 사물을 AI가 실시간으로 인식하고, 필요한 정보를 시야에 즉시 제공하는 **미래형 AI 스마트 선글라스**이다.

스마트폰을 꺼내 검색하는 과정을 줄이고, 일상 속에서 더욱 빠르고 직관적인 정보 탐색 경험을 제공하는 **차세대 AI 웨어러블 기기**이다.

## 광고 목적

**제품 인지 (Awareness)**

Galaxy Glass라는 새로운 AI 웨어러블 카테고리를 소비자에게 처음 각인시키는 것을 목표로 한다.

## 타깃 고객

- AI 서비스를 일상적으로 활용하는 **20~40대 소비자**
- 새로운 IT 기기와 웨어러블 제품에 관심이 많은 **얼리어답터**
- 쇼핑, 여행 등 다양한 상황에서 **빠른 정보 확인**을 원하는 사용자

## 톤앤매너

- 세련되고 **미래지향적**인 분위기
- 차갑지 않고 **일상 속에 자연스럽게** 녹아드는 따뜻함
- 마지막 씬에서 **유머러스한 반전**으로 친근감 부여
- 색감: **따뜻한 웜톤을 기반으로 HUD와 엔딩에서 삼성 블루를 포인트 컬러로 활용**

## 브랜드 슬로건

> **“필요한 정보를, 눈앞에서.”**
>

| 기능 | 설명 |
| --- | --- |
| AI 실시간 사물 인식 | 바라보는 사물을 AI가 즉시 인식 |
| 음성 명령 검색 | 말 한마디로 원하는 정보 검색 |
| HUD 정보 표시 | 시야 안에 실시간으로 정보 표출 |

> 이미지 생성에는 기존에 구독 중이던 ChatGPT Plus를 사용하였으며, 그 외 비디오 생성, 음성 합성, 배경음악 생성 및 통합 편집은 각 도구의 무료 플랜 또는 무료 기능 범위에서 진행하였다.
> 

## 제작 전략 및 제약 대응

- 영상 생성 크레딧을 효율적으로 사용하기 위해 전체 광고를 4개의 씬으로 구성하여 핵심 메시지를 압축하였다.
- ChatGPT Plus를 이용해 각 씬의 이미지를 먼저 확정한 뒤, Luma Dream Machine의 무료 플랜으로 이미지 기반 영상 변환을 진행하여 불필요한 재생성을 최소화하였다.
- 캐릭터의 헤어, 의상, 선글라스와 매장의 조명·벽 색상을 프롬프트에 반복적으로 명시하여 캐릭터와 배경의 일관성을 유지하였다.
- 짧은 러닝타임 안에서 메시지를 효과적으로 전달하기 위해 복잡한 액션보다 걷기, 정지, 빠른 줌, 제품 회전 등 단순한 모션 중심으로 구성하였다.
- 영상 생성 결과가 의도와 다를 경우 프롬프트 수정과 반복 생성을 병행하며 가장 완성도가 높은 결과물을 최종본으로 선정하였다.
- 음성(ElevenLabs), 배경음악(Suno AI), 최종 편집(CapCut)은 모두 무료 플랜 및 무료 기능 범위 내에서 제작하여 추가 비용을 최소화하였다.
